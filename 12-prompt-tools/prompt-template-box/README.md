# 프롬프트 템플릿 상자

{{변수}}가 들어간 프롬프트를 저장해 두고, 빈칸만 채워 한 번에 복사합니다.

## 해결하는 문제
자주 쓰는 프롬프트를 메모장에 두고 복사해서 일부만 고쳐 쓰는 일이 번거롭습니다. 기존 프롬프트 관리 확장은 특정 AI 사이트만 지원하거나 여러 사이트 접근 권한·사용 추적이 따라옵니다. 이 확장은 사이트 접근 권한 없이 저장소 권한만으로 어떤 서비스에서도 씁니다.

## 설치 방법 (처음 하는 분 기준)
1. 이 저장소에서 초록색 **Code** 버튼 → **Download ZIP**으로 내려받아 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions` 를 입력하고 Enter를 누릅니다.
3. 오른쪽 위 **개발자 모드** 스위치를 켭니다.
4. 왼쪽 위 **압축해제된 확장 프로그램을 로드합니다**를 누르고, 이 폴더(`manifest.json`이 보이는 `prompt-template-box` 폴더)를 고릅니다.
5. 주소창 오른쪽 퍼즐 모양 아이콘 → 이 확장의 핀 아이콘을 눌러 고정합니다.

## 사용법
1. 아이콘 → **새로 만들기**에서 이름과 내용을 적습니다. 바꿔 쓸 부분은 `{{회의 내용}}` 처럼 겹중괄호로 감쌉니다.
2. 저장하면 템플릿 고르는 칸에 나타납니다. 고르면 변수마다 입력칸이 생깁니다.
3. 칸을 채우면 아래 **완성된 프롬프트**가 바로 바뀝니다. **복사하기**를 누르고 AI 서비스에 붙여 넣습니다.
4. 비워 둔 변수는 `{{이름}}` 그대로 남고, 복사할 때 비어 있는 칸 이름을 알려 줍니다.
5. 아래 **백업·복원**에서 파일로 내보내고 불러올 수 있습니다.

## 권한이 필요한 이유
| 권한 | 이유 |
|---|---|
| `storage` | 템플릿과 마지막 선택을 내 브라우저에 저장하기 위해 |

모든 사이트 접근 권한은 요청하지 않으며, 입력한 내용을 외부 서버로 보내지 않습니다.

## 검증한 것
- 변수 찾기·채우기·불러오기 로직 단위 테스트 통과(중복 변수, 공백 변수, `$&` 같은 특수 글자).
- 실제 Chromium에서 확인: 템플릿 만들기, 변수 입력에 따른 미리보기(`표로 정리: 안건A / 표`), 클립보드 복사 내용 일치, 새로고침 후 유지, 삭제.

## 한계 (확인하지 못했거나 지원하지 않는 것)
- AI 사이트 입력창에 **자동으로 넣어 주지 않습니다.** 복사 후 직접 붙여 넣습니다(이 덕분에 사이트 접근 권한이 필요 없습니다).
- 파일 불러오기·내보내기 버튼의 동작은 자동 테스트하지 못했습니다(미검증).
- 한 템플릿 내용은 최대 2만 자까지만 불러옵니다.
