# 해시태그 세트 상자

자주 쓰는 해시태그 묶음에 이름을 붙여 저장하고 한 번에 복사합니다.

## 해결하는 문제
인스타그램·블로그에 글을 올릴 때마다 해시태그를 메모장에서 찾아 붙이는 번거로움, 중복·# 빠짐 실수를 줄여 줍니다. 계정, 서버, 유료 기능이 없습니다.

## 설치 방법 (처음 하는 분 기준)
1. 이 저장소에서 초록색 **Code** 버튼 → **Download ZIP**으로 내려받아 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions` 를 입력하고 Enter를 누릅니다.
3. 오른쪽 위 **개발자 모드** 스위치를 켭니다.
4. 왼쪽 위 **압축해제된 확장 프로그램을 로드합니다**를 누르고, 이 폴더(`manifest.json`이 보이는 `hashtag-set-box` 폴더)를 고릅니다.
5. 주소창 오른쪽 퍼즐 모양 아이콘 → 이 확장의 핀 아이콘을 눌러 고정합니다.

## 사용법
1. 툴바의 확장 아이콘을 누릅니다.
2. **세트 이름**과 **해시태그**를 적고 **저장**을 누릅니다. 띄어쓰기·쉼표·줄바꿈으로 구분하고, `#`은 안 써도 자동으로 붙으며 같은 태그는 한 번만 남습니다.
3. 저장한 세트 아래 **복사**를 누르면 `#맛집 #카페` 형태로 복사되어 글에 바로 붙여 넣을 수 있습니다.
4. 태그가 30개를 넘으면 인스타그램 한도 안내가 나옵니다. **고치기**로 덮어쓰고, **지우기**로 삭제합니다.
5. **백업 파일 저장 / 불러오기**로 다른 컴퓨터로 옮길 수 있습니다(JSON 파일).

## 권한이 필요한 이유
| 권한 | 이유 |
|---|---|
| `storage` | 저장한 세트를 내 브라우저에 보관하기 위해 |

모든 사이트 접근 권한은 요청하지 않으며, 입력한 내용을 밖으로 보내지 않습니다. 설정과 기록은 `chrome.storage`(내 브라우저)에만 저장됩니다.

## 검증한 것
- 실제 크롬(Chromium, 확장 불러오기)에서 팝업을 열어 시험: 중복·`#` 정리(3개), 저장·표시, 30개 초과 안내, 고치기 덮어쓰기, 새로 열어도 유지, 삭제, 이름 없음 오류, 콘솔 오류 없음.
- 복사 버튼을 눌렀을 때 '복사했습니다' 안내가 나오는 것까지 확인했습니다(복사 실패 시 예비 방법도 넣음).

## 한계 (확인하지 못했거나 지원하지 않는 것)
- **툴바 아이콘을 눌러 팝업을 여는 실제 흐름은 자동 테스트로 확인하지 못했습니다.** 시험은 팝업 화면 주소(`chrome-extension://…/popup.html`)를 직접 열어서 했습니다. 설치 후 한 번 직접 눌러 확인해 주세요.
- **복사된 글자를 실제로 붙여 넣어 확인하지는 못했습니다.** 시험 환경에서 클립보드 읽기가 막혀 안내 문구만 확인했습니다.
- 인기 해시태그 추천·검색량 분석은 없습니다(외부 서버를 쓰지 않기 위함). 30개 한도 숫자는 안내용이며 플랫폼 정책은 바뀔 수 있습니다.
- 백업 불러오기 파일 선택 창은 자동 시험하지 못했습니다(코드만 문법 검사).
