# 영어 단어 상자

웹에서 영어를 읽다가 모르는 단어를 **드래그 → 우클릭 한 번**으로 예문과 함께 담아 두고, 간격을 두고 복습하는 크롬 확장 프로그램입니다. 계정·서버 없이 내 브라우저에만 저장됩니다.

## 해결하는 문제
영어 글을 읽다가 모르는 단어를 만나도 흐름을 끊기 싫어서 그냥 넘어가고, 나중에는 어떤 단어였는지 잊어버리는 일을 줄여 줍니다.

## 설치 방법 (처음 하는 분 기준)
1. 이 저장소에서 초록색 **Code** 버튼 → **Download ZIP**으로 내려받아 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions` 를 입력하고 Enter를 누릅니다.
3. 오른쪽 위 **개발자 모드** 스위치를 켭니다.
4. 왼쪽 위 **압축해제된 확장 프로그램을 로드합니다**를 누르고, 이 폴더(`manifest.json`이 보이는 `word-box` 폴더)를 고릅니다.
5. 주소창 오른쪽 퍼즐 모양 아이콘 → 이 확장의 핀 아이콘을 눌러 고정합니다.

## 사용법
1. 영어 페이지에서 단어(또는 6낱말 이하 표현)를 **드래그**하고 **오른쪽 클릭 → 단어 상자에 담기**를 누릅니다. 확장 아이콘에 `+1`이 잠깐 나타납니다. (`이미`는 이미 담긴 단어, `!`는 너무 길거나 비어 있음)
2. 아이콘을 누르면 **복습** 탭에 지금 복습할 단어가 나옵니다. **뜻 보기**를 누르고, 뜻을 적은 뒤 **알았어요**/**몰랐어요**를 누르세요.
   - 알았어요: 한 단계 위로(다음 복습이 10분 → 1일 → 3일 → 7일 → 14일 → 30일로 늘어남)
   - 몰랐어요: 1단계로(10분 뒤 다시)
3. **목록** 탭에서 단어·뜻 검색, 뜻 고치기, 삭제를 할 수 있습니다.
4. **추가·내보내기** 탭에서 직접 단어를 담거나, **CSV로 저장**(엑셀에서 한글 안 깨짐)할 수 있습니다. **전체 지우기**는 두 번 눌러야 실행됩니다.

## 권한이 필요한 이유
| 권한 | 이유 |
|---|---|
| `contextMenus` | 우클릭 메뉴에 "단어 상자에 담기"를 넣기 위해 |
| `activeTab` | 우클릭한 순간 그 탭에서 선택한 글이 들어 있는 문장을 가져오기 위해 |
| `scripting` | 그 탭에서 문장을 읽는 코드를 실행하기 위해 |
| `storage` | 담은 단어를 브라우저에 저장하기 위해 |

모든 사이트 접근 권한은 요청하지 않으며, 단어와 예문을 밖으로 보내지 않습니다. (목록·복습 화면의 **사전 ↗** 링크는 내가 눌렀을 때만 그 단어로 네이버 영어사전이 새 탭에서 열립니다.)

## 검증한 것
- 코어 로직(단어 정리, 문장 자르기, 중복 처리, 복습 단계·시간, CSV 수식 방어) 단위 테스트 통과.
- 실제 크롬(Chrome for Testing 153)에서 확인: 메뉴 클릭 처리 시 단어와 문장 예문, 출처 주소·제목이 저장됨 / 같은 단어(대소문자 달라도)는 한 번만 / 7낱말 이상은 거절 / 복습 카드에서 예문 속 단어 강조 / "알았어요" 후 2단계·뜻 저장·다음 복습 약 1일 뒤 / 목록 검색 / CSV 내려받기(BOM, 헤더, 줄 수) / 전체 지우기 두 번 확인.
- 시험 중 **쉼표가 붙게 선택하면 예문을 못 찾는 문제**를 발견해 고쳤습니다.

## 한계 (확인하지 못했거나 지원하지 않는 것)
- **실제로 마우스 오른쪽 버튼을 눌러 나오는 메뉴 화면은 자동 테스트로 누르지 못했습니다.** 대신 같은 처리 코드를 직접 호출해 확인했습니다. 설치 후 한 번 직접 시험해 주세요.
- 뜻을 자동으로 알려 주지 않습니다. 직접 적거나 **사전 ↗** 링크를 눌러 확인하세요.
- 발음 듣기, 영상 자막, 문장 번역은 없습니다. 다른 기기와 동기화되지 않습니다.
- 이미지·PDF 뷰어·입력칸 안의 글처럼 우클릭 "선택" 메뉴가 안 뜨는 곳에서는 담을 수 없습니다(이때는 **추가·내보내기** 탭에서 직접 입력).
- 크롬 설정 화면, 웹 스토어 같은 보호된 페이지에서는 예문 없이 단어만 담길 수 있습니다.
