# 로컬 단축어 확장기

단축어를 쓰고 **Tab**을 누르면 미리 저장해 둔 문구로 바뀌는 크롬 확장 프로그램입니다. 계정도 서버도 없이 내 브라우저에만 저장됩니다.

## 해결하는 문제
메일, 댓글, 문의 답변처럼 매일 같은 문장을 반복해서 치는 일을 줄여 줍니다. 예를 들어 `;인사` + Tab → `안녕하세요.`

## 설치 방법 (처음 하는 분 기준)
1. 이 저장소에서 초록색 **Code** 버튼 → **Download ZIP**으로 내려받아 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions` 를 입력하고 Enter를 누릅니다.
3. 오른쪽 위 **개발자 모드** 스위치를 켭니다.
4. 왼쪽 위 **압축해제된 확장 프로그램을 로드합니다**를 누르고, 이 폴더(`manifest.json`이 보이는 폴더)를 고릅니다.
5. 주소창 오른쪽 퍼즐 모양 아이콘 → 이 확장의 핀 아이콘을 눌러 고정합니다.

## 사용법
1. 툴바의 확장 아이콘을 눌러 **단축어**(예: `;주소`)와 **바뀔 내용**을 입력하고 **저장**을 누릅니다.
2. 아무 글 입력칸에서 단축어를 쓰고 **Tab**을 누르면 바뀝니다.
3. 단축어가 아닌 글에서 Tab을 누르면 평소처럼 다음 칸으로 이동합니다.
4. 자리표시자: `{날짜}` → 2026-10-29, `{시간}` → 05:07, `{요일}` → 목
5. **내보내기/가져오기**(JSON)로 다른 컴퓨터에 옮길 수 있습니다.

## 권한이 필요한 이유
| 권한 | 이유 |
|---|---|
| `storage` | 단축어 목록을 내 브라우저에 저장하기 위해 |
| 모든 사이트의 입력칸 읽기(콘텐츠 스크립트) | 어느 사이트에서든 Tab을 눌렀을 때 단축어를 찾아 바꾸기 위해. 입력한 글을 밖으로 보내지 않습니다 |

## 검증한 것
- 핵심 함수 단위 테스트 통과, 실제 크롬에서 textarea·한 줄 입력칸·서식 입력칸(contenteditable) 모두 확장 확인, 단축어가 아닐 때 Tab 이동 유지 확인.

## 한계 (확인하지 못했거나 지원하지 않는 것)
- **한글 입력기로 조합 중일 때 Tab은 확인하지 못했습니다.** 테스트는 글자를 직접 넣는 방식이었습니다. 단축어 앞에 `;`를 붙이고 마지막 글자를 완성한 뒤 Tab을 누르는 것을 권합니다.
- 비밀번호·이메일·숫자 입력칸에서는 동작하지 않습니다.
- 서식 입력칸에서는 단축어가 한 글 조각 안에 있어야 합니다. 일부 웹 에디터(그림자 DOM 등)에서는 동작하지 않을 수 있습니다.
- 서식(굵게 등)이나 입력 양식(폼) 기능은 없습니다. 글만 바꿉니다.
