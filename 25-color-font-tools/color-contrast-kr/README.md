# 글자색 대비 검사기 (WCAG)

글자색과 배경색을 넣으면 **명도 대비**를 계산해 읽기 편한지(WCAG AA·AAA)를 한글로 알려 주고, 기준에 못 미치면 가까운 글자색을 제안합니다.

## 해결하는 문제
회색 글자가 흐려 읽기 힘든 화면은 눈이 불편한 분뿐 아니라 밝은 야외에서도 문제가 됩니다. 디자인할 때 "이 색 조합이 괜찮은가?"를 바로 확인하고, 안 되면 어느 색으로 바꾸면 되는지 알려 줍니다.

## 설치 방법 (처음 하는 분용)
1. 크롬 주소창에 `chrome://extensions` 입력 후 Enter
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** 클릭
4. 이 폴더(`color-contrast-kr`) 선택

## 사용법
1. 툴바 아이콘을 누릅니다.
2. 글자색·배경색을 색상 칸이나 `#333`, `#333333`, `rgb(51,51,51)` 형식으로 넣습니다. (스포이트 버튼은 크롬이 지원할 때만 보입니다.)
3. 미리보기와 대비 값, 보통 글자·큰 글자·아이콘 기준 통과 여부가 표시됩니다.
4. 미달이면 제안 버튼(더 어둡게/더 밝게)을 눌러 글자색을 바로 바꿉니다.
5. ⇄ 버튼으로 글자색과 배경색을 서로 바꿉니다.

## 권한이 필요한 이유
- `storage`: 마지막에 쓴 두 색만 저장합니다. 웹 페이지에는 접근하지 않고 아무것도 전송하지 않습니다.

## 한계
- 투명도(alpha)가 있는 색, 그라데이션 배경, 그림 위 글자는 계산하지 않습니다.
- 색 이름(red 등)과 hsl() 입력은 지원하지 않습니다(HEX·rgb만).
- 제안은 색상·채도는 그대로 두고 밝기만 바꾸는 방식이라 디자인 의도와 다를 수 있습니다.
- 스포이트(EyeDropper)는 실제 화면 선택 동작을 자동 시험하지 못해 직접 확인이 필요합니다.
