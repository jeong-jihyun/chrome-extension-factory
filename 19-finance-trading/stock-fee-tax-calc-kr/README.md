# 주식 수수료·세금 손익 계산기

매수가·매도가·수량에 수수료와 거래세를 반영해 실제 순손익과 손익분기 매도가를 계산합니다.

## 해결하는 문제
증권앱의 평가손익은 수수료·세금이 빠진 경우가 많아 "팔고 나니 생각보다 적게 남는" 일이 생깁니다. 매도 시 거래세까지 넣은 순손익과 본전이 되는 매도가를 알려 줍니다.

## 설치 방법 (처음 하는 분 기준)
1. 이 저장소에서 초록색 **Code** 버튼 → **Download ZIP**으로 내려받아 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions` 를 입력하고 Enter를 누릅니다.
3. 오른쪽 위 **개발자 모드** 스위치를 켭니다.
4. 왼쪽 위 **압축해제된 확장 프로그램을 로드합니다**를 누르고, 이 폴더(`manifest.json`이 보이는 `stock-fee-tax-calc-kr` 폴더)를 고릅니다.
5. 주소창 오른쪽 퍼즐 모양 아이콘 → 이 확장의 핀 아이콘을 눌러 고정합니다.

## 사용법
1. 툴바의 확장 아이콘을 누릅니다.
2. **시장**(코스피·코스닥·세금 없음·직접 입력)을 고르면 세금(%) 칸이 자동으로 채워집니다. 세율은 직접 고칠 수도 있습니다.
3. 매수가, 매도가, 수량, 매수·매도 수수료(%)를 적습니다. 수수료 0.015%는 예시이므로 내 증권사 값으로 바꿔 주세요.
4. 위에 순손익(원, %)이 크게 나오고, 아래 표에 수수료·세금 내역과 **손익분기 매도가**가 나옵니다. 입력은 자동 저장됩니다.

## 권한이 필요한 이유
| 권한 | 이유 |
|---|---|
| `storage` | 마지막 입력값과 내 수수료율을 저장하기 위해 |

모든 사이트 접근 권한은 요청하지 않으며, 입력한 내용을 밖으로 보내지 않습니다. 설정과 기록은 `chrome.storage`(내 브라우저)에만 저장됩니다.

## 검증한 것
- 실제 크롬(Chromium, 확장 불러오기)에서 팝업 시험: 70,000원에 10주 매수, 77,000원 매도 → 순손익 +68,241원(+9.75%), 손익분기 70,162원, 시장 선택 시 세율 변경, 세율을 고치면 '직접 입력'으로 전환, 저장 유지, 손실(음수) 표시, 콘솔 오류 없음.
- 수수료·세금은 원 단위 미만 절사로 계산했습니다(증권사마다 다를 수 있음).

## 한계 (확인하지 못했거나 지원하지 않는 것)
- **툴바 아이콘을 눌러 팝업을 여는 실제 흐름은 자동 테스트로 확인하지 못했습니다.** 시험은 팝업 화면 주소(`chrome-extension://…/popup.html`)를 직접 열어서 했습니다. 설치 후 한 번 직접 눌러 확인해 주세요.
- **세율은 참고값입니다.** 코스피 0.20%(거래세 0.05%+농어촌특별세 0.15%), 코스닥 0.20%는 2026년 1월 이후 매도분 기준으로 한 안내 글(studygov.kr)에서 확인한 값이며, 공식 기관 자료로 직접 확인한 것이 아닙니다. 바뀌면 직접 고쳐 쓰세요.
- ETF·ETN·해외 주식은 세금 체계가 달라 시장 선택에 없습니다. 면세 여부를 확인해 '세금 없음' 또는 직접 입력을 쓰세요.
- 양도소득세·배당세·환율·최소 수수료·유관기관 수수료는 계산하지 않습니다. 투자 조언이 아닙니다.
