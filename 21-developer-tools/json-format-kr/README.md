# JSON 정리·검사 (한글)

JSON을 붙여 넣으면 보기 좋게 정리하고, 오류가 있으면 **몇 째 줄 몇 번째 글자**인지 한글로 알려 주는 확장 프로그램입니다.

## 해결하는 문제
API 응답이나 설정 파일의 JSON이 한 줄로 길게 붙어 있으면 읽기 어렵습니다. 오류가 나면 영어 메시지만 나와 어디가 틀렸는지 찾기 힘듭니다. 이 확장은 한글로 위치와 이유를 알려 주고 그 자리를 선택해 보여 줍니다.

## 설치 방법 (처음 하는 분용)
1. 크롬 주소창에 `chrome://extensions` 를 입력하고 Enter
2. 오른쪽 위 **개발자 모드**를 켭니다
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다
4. 이 폴더(`manifest.json`이 있는 `json-format-kr`)를 선택합니다
5. 툴바의 퍼즐 모양 아이콘에서 핀 고정을 하면 편합니다

## 사용법
1. 툴바 아이콘을 누르고 JSON을 붙여 넣습니다.
2. **보기 좋게 정리** / **한 줄로 줄이기** / **검사만** 중 하나를 누릅니다.
3. 오류가 있으면 위치가 한글로 나오고 입력창에서 그 글자가 선택됩니다.
4. 들여쓰기(2칸·4칸·탭)와 키 이름순 정렬은 선택할 수 있고 설정은 저장됩니다.

## 권한이 필요한 이유
- `storage`: 들여쓰기·정렬 설정만 저장합니다. 입력한 JSON은 저장하지 않습니다.
- 그 밖의 권한(웹 페이지 접근, 네트워크 등)은 요청하지 않습니다. 데이터는 밖으로 나가지 않습니다.

## 한계
- 팝업에서 붙여 넣는 방식입니다. 열려 있는 웹 페이지의 JSON을 자동으로 바꿔 보여 주지는 않습니다.
- 주석이 들어간 JSON(JSONC)이나 작은따옴표 JSON은 오류로 처리합니다(표준 JSON만 지원).
- 아주 큰 파일(수십 MB)은 팝업이 느려질 수 있습니다.
- 정리하면 숫자가 JavaScript 범위를 넘는 큰 정수는 값이 바뀔 수 있습니다.
