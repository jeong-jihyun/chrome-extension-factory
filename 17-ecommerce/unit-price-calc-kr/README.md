# 단위가격 비교 계산기

가격·용량·묶음 수를 넣으면 100g당·100ml당·1개당 가격으로 바꿔 가장 싼 상품을 알려 줍니다.

## 해결하는 문제
"500g 3,000원 vs 1kg 5,000원 vs 2L 2병"처럼 용량·단위가 달라 어느 쪽이 싼지 바로 알기 어려운 문제를 풀어 줍니다. 쇼핑몰 페이지를 읽지 않고, 내가 넣은 숫자만 계산합니다.

## 설치 방법 (처음 하는 분 기준)
1. 이 저장소에서 초록색 **Code** 버튼 → **Download ZIP**으로 내려받아 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions` 를 입력하고 Enter를 누릅니다.
3. 오른쪽 위 **개발자 모드** 스위치를 켭니다.
4. 왼쪽 위 **압축해제된 확장 프로그램을 로드합니다**를 누르고, 이 폴더(`manifest.json`이 보이는 `unit-price-calc-kr` 폴더)를 고릅니다.
5. 주소창 오른쪽 퍼즐 모양 아이콘 → 이 확장의 핀 아이콘을 눌러 고정합니다.

## 사용법
1. 툴바의 확장 아이콘을 누릅니다.
2. 상품마다 **가격(원)**, **용량/수량**, 단위(g·kg·ml·L·개·장·m), **묶음 수**(예: 2병이면 2)를 적습니다.
3. 아래 표에 기준 단위가격이 나오고, 같은 종류 중 가장 싼 상품에 **★최저** 표시가 붙습니다.
4. **상품 추가**로 줄을 늘리고, **모두 지우기**로 초기화합니다. 입력은 자동 저장됩니다.

## 권한이 필요한 이유
| 권한 | 이유 |
|---|---|
| `storage` | 마지막에 입력한 상품을 저장해 다시 열 때 이어 쓰기 위해 |

모든 사이트 접근 권한은 요청하지 않으며, 입력한 내용을 밖으로 보내지 않습니다. 설정과 기록은 `chrome.storage`(내 브라우저)에만 저장됩니다.

## 검증한 것
- 실제 크롬(Chromium, 확장 불러오기)에서 팝업 시험: 500g 3,000원=100g당 600원, 1kg 5,000원=500원 계산과 ★최저 표시, 저장 후 다시 열어도 줄 유지, 초기화, 콘솔 오류 없음.
- 계산 함수는 Node에서 따로 검산했습니다(2L 2병 1,000원=100ml당 50원 등).

## 한계 (확인하지 못했거나 지원하지 않는 것)
- **툴바 아이콘을 눌러 팝업을 여는 실제 흐름은 자동 테스트로 확인하지 못했습니다.** 시험은 팝업 화면 주소(`chrome-extension://…/popup.html`)를 직접 열어서 했습니다. 설치 후 한 번 직접 눌러 확인해 주세요.
- 쇼핑몰 화면에서 자동으로 용량·가격을 읽어 오지 않고 손으로 입력합니다(권한 최소화를 위한 선택).
- 무게·부피·개수·길이는 서로 비교하지 못하고 종류별로 따로 비교합니다. 배송비·할인 쿠폰은 계산하지 않습니다.
