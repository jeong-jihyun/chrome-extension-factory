# 한글 글쓰기 점검기

한국어 글의 **긴 문장, 같은 끝말·접속어 반복, 군더더기 표현, 이중 피동**을 규칙으로 찾아 알려 주는 크롬 확장 프로그램입니다. 글이 서버로 나가지 않고 브라우저 안에서만 검사합니다.

## 해결하는 문제
블로그·보고서를 쓰고 나서 "읽기 어렵다"는 말을 들었을 때 어디가 문제인지 찾기 어려운 점을 줄여 줍니다. 쓴 글을 붙여 넣거나, 페이지에서 드래그해서 가져오면 점검 결과가 바로 나옵니다.

## 설치 방법 (처음 하는 분 기준)
1. 이 저장소에서 초록색 **Code** 버튼 → **Download ZIP**으로 내려받아 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions` 를 입력하고 Enter를 누릅니다.
3. 오른쪽 위 **개발자 모드** 스위치를 켭니다.
4. 왼쪽 위 **압축해제된 확장 프로그램을 로드합니다**를 누르고, 이 폴더(`manifest.json`이 보이는 `hangul-writing-check` 폴더)를 고릅니다.
5. 주소창 오른쪽 퍼즐 모양 아이콘 → 이 확장의 핀 아이콘을 눌러 고정합니다.

## 사용법
1. 확장 아이콘을 누르고 입력칸에 글을 **붙여 넣습니다.** 또는 페이지에서 글을 드래그한 뒤 **선택한 글 가져오기**를 누릅니다.
2. 위쪽에 글자 수(공백 제외), 문장 수, 평균·가장 긴 문장 길이, 문단 수, 읽는 시간(분당 500자 어림)이 나옵니다.
3. 아래에는 찾은 문제가 카드로 나옵니다. 각 카드에 **어떻게 고치면 좋은지**와 해당 문장(최대 5개)이 함께 나옵니다.
   - 긴 문장 / 같은 끝말이 4문장 이상 이어짐 / 접속어로 시작하는 문장 / 자주 반복되는 낱말
   - 군더더기: “~ㄹ 수 있다”, “~것 같다”, “~에 대해(서)”, “~을 통해(서)”, “~에 있어(서)”, “~것이다”, “~하게 되다”, “생각합니다”, 강조어
   - 이중 피동(“되어지다”, “보여지다”, “쓰여지다” 등) / 긴 문단
4. **기준 바꾸기**에서 긴 문장·긴 문단 글자 수, 반복 낱말 횟수를 바꿀 수 있습니다. 기준은 저장됩니다.

## 권한이 필요한 이유
| 권한 | 이유 |
|---|---|
| `activeTab` | 아이콘을 누른 지금 이 탭에서 내가 선택한 글을 가져오기 위해 (누를 때만 허용됨) |
| `scripting` | 그 탭에서 선택한 글을 읽는 코드를 실행하기 위해 |
| `storage` | 기준(글자 수 등) 설정을 저장하기 위해 |

모든 사이트 접근 권한은 요청하지 않으며, 글을 밖으로 보내지도 저장하지도 않습니다.

## 검증한 것
- 규칙 로직 단위 테스트 통과(긴 문장, 접속어, 이중 피동, 같은 끝말 연속, 군더더기, 반복 낱말, 긴 문단, 기준 변경). 시험 중 **"보여집니다"처럼 받침이 붙은 이중 피동을 놓치는 버그**를 발견해 고쳤습니다.
- 실제 크롬(Chrome for Testing 153)에서 확인: 페이지에서 선택한 글 가져오기와 요약 표시, 이중 피동·군더더기 표현 표시, 기준(20자)을 바꾸면 바로 반영, 기준 저장 후 유지. 화면 캡처로 눈으로도 확인했습니다.

## 한계 (확인하지 못했거나 지원하지 않는 것)
- **맞춤법·띄어쓰기 검사가 아닙니다.** 형태소 분석 없이 글자 모양만 보는 규칙 검사라 틀릴 수 있습니다. 특히 반복 낱말(조사를 어림으로 뗌)과 접속어는 어림입니다. 일부러 쓴 표현이면 무시하세요.
- 기본 기준(문장 80자, 문단 300자 등)은 표준이 아니라 이 확장이 정한 기본값입니다. 글의 성격에 맞게 조절하세요.
- 문장을 자동으로 고쳐 주지는 않습니다.
- **툴바 아이콘을 눌러 `activeTab` 권한이 부여되는 실제 흐름은 자동 테스트로 확인하지 못했습니다.** 시험은 로컬 주소 접근 권한을 더한 복사본으로 했습니다(저장소 원본 manifest는 그대로). 붙여 넣기는 권한과 상관없이 동작합니다.
- 크롬 설정 화면, 웹 스토어 같은 보호된 페이지에서는 가져올 수 없습니다.
