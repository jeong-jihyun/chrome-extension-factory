# 글자·바이트 세기

글자 수와 바이트 수를 한 번에 세어 주는 크롬 확장 프로그램입니다. **한글 2바이트(EUC-KR/CP949) 기준과 3바이트(UTF-8) 기준을 모두** 보여 주고, 바이트 한도에 맞춰 자르거나 공백으로 채워 줍니다.

## 해결하는 문제
입력칸에 "최대 100바이트" 같은 제한이 있거나, 오래된 시스템·전문(고정 길이 전문)에 맞춰 글을 넣어야 할 때 바이트를 손으로 세는 일을 줄여 줍니다.

## 설치 방법 (처음 하는 분 기준)
1. 이 저장소에서 초록색 **Code** 버튼 → **Download ZIP**으로 내려받아 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions` 를 입력하고 Enter를 누릅니다.
3. 오른쪽 위 **개발자 모드** 스위치를 켭니다.
4. 왼쪽 위 **압축해제된 확장 프로그램을 로드합니다**를 누르고, 이 폴더(`manifest.json`이 보이는 `byte-counter-kr` 폴더)를 고릅니다.
5. 주소창 오른쪽 퍼즐 모양 아이콘 → 이 확장의 핀 아이콘을 눌러 고정합니다.

## 사용법
1. 세고 싶은 글을 페이지에서 **드래그**한 뒤 확장 아이콘을 누르고 **선택한 글 가져오기**를 누릅니다. (글을 직접 붙여 넣어도 됩니다.)
2. 글자 수, 공백 제외 글자 수, **바이트(한글 2)**, **바이트(한글 3)**, 낱말 수, 줄 수가 나옵니다.
3. **바이트 한도**에서 기준(EUC-KR/CP949 또는 UTF-8)과 숫자를 넣으면 `9 / 7 바이트 · 2바이트 초과`처럼 남은/초과 바이트가 나옵니다.
4. **한도에 맞춰 자르기**: 한도를 넘지 않는 글자까지만 남깁니다(글자 중간은 자르지 않음).
5. **공백으로 채워 복사**: 오른쪽을 공백으로 채워 정확히 한도 바이트로 만든 글을 복사합니다.
6. 줄바꿈을 2바이트(`\r\n`)로 계산해야 하면 체크하세요. 기준과 한도는 저장됩니다.

## 권한이 필요한 이유
| 권한 | 이유 |
|---|---|
| `activeTab` | 아이콘을 누른 지금 이 탭에서 내가 선택한 글을 가져오기 위해 (누를 때만 허용됨) |
| `scripting` | 그 탭에서 선택한 글을 읽는 코드를 실행하기 위해 |
| `storage` | 바이트 기준·한도 같은 내 설정을 저장하기 위해 |

모든 사이트 접근 권한은 요청하지 않으며, 글을 밖으로 보내지 않습니다. 가져온 글은 저장하지 않습니다.

## 검증한 것
- 계산 로직 단위 테스트 통과: 한글 2·3바이트, 영문·숫자, 이모지, 줄바꿈 옵션, 자르기(글자 중간 안 자름), 공백 채우기.
- 실제 크롬(Chrome for Testing 153)에서 확인: 페이지에서 선택한 글 가져오기, 글자 수·바이트 표시(손으로 센 값과 일치: 글자 20, 공백 제외 16, 한글2 기준 34바이트, UTF-8 48바이트), 한도 초과 표시, 자르기(`가나다abc` 7바이트 → `가나다a`), UTF-8 10바이트 자르기, 설정 유지.

## 한계 (확인하지 못했거나 지원하지 않는 것)
- **EUC-KR/CP949 바이트는 어림값입니다.** 영문·숫자·기호는 1바이트, 한글·한자 등 그 밖의 문자는 2바이트, 이모지는 `?` 1바이트로 쳤습니다. 실제 변환과 다른 글자가 있을 수 있습니다.
- **툴바 아이콘을 눌러 `activeTab` 권한이 부여되는 실제 흐름은 자동 테스트로 확인하지 못했습니다.** 시험은 로컬 주소 접근 권한을 더한 복사본으로 했습니다(저장소 원본 manifest는 그대로). 설치 후 한 번 직접 눌러 확인해 주세요.
- "공백으로 채워 복사"는 클립보드 권한이 필요한 동작이라 자동 테스트하지 못했습니다. (자르기·채우기 계산은 단위 테스트로 확인)
- 드래그하는 즉시 숫자가 뜨지는 않고, **선택한 글 가져오기**를 눌러야 합니다. 사이트마다 글자·줄바꿈을 세는 방법이 달라 그 사이트의 표시와 다를 수 있습니다.
- 크롬 설정 화면, 웹 스토어 같은 보호된 페이지에서는 가져올 수 없습니다(붙여 넣기는 가능).
