# 페이지 메모

지금 보는 **페이지** 또는 **사이트 전체**에 짧은 메모를 남기고, 모든 메모를 검색하고 내보내는 크롬 확장 프로그램입니다. 메모는 내 브라우저에만 저장됩니다.

## 해결하는 문제
"이 글에서 어디까지 읽었지", "이 쇼핑몰은 배송이 느림" 같은 짧은 기억을 페이지에 붙여 두고 나중에 검색해서 찾습니다. 주소 끝의 `#`이나 광고 꼬리표(`utm_source` 등)가 달라도 같은 페이지의 메모로 이어집니다.

## 설치 방법 (처음 하는 분 기준)
1. 이 저장소에서 초록색 **Code** 버튼 → **Download ZIP**으로 내려받아 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions` 를 입력하고 Enter를 누릅니다.
3. 오른쪽 위 **개발자 모드** 스위치를 켭니다.
4. 왼쪽 위 **압축해제된 확장 프로그램을 로드합니다**를 누르고, 이 폴더(`manifest.json`이 보이는 폴더)를 고릅니다.
5. 주소창 오른쪽 퍼즐 모양 아이콘 → 이 확장의 핀 아이콘을 눌러 고정합니다.

## 사용법
1. 메모를 남기고 싶은 페이지에서 툴바의 확장 아이콘을 누릅니다.
2. **이 페이지** 또는 **이 사이트 전체**를 고르고 글을 적습니다. 적으면 자동으로 저장됩니다.
3. 같은 페이지로 돌아와 아이콘을 누르면 메모가 그대로 있습니다.
4. **전체 메모** 탭에서 검색하고, 제목을 누르면 그 페이지가 새 탭으로 열립니다.
5. **글 파일로 내보내기**(.txt) 또는 **JSON으로 내보내기**로 백업합니다.
6. 메모 내용을 모두 지우면 그 메모가 삭제됩니다.

## 권한이 필요한 이유
| 권한 | 이유 |
|---|---|
| `storage` | 메모를 내 브라우저에 저장하기 위해 |
| `activeTab` | 아이콘을 눌렀을 때 지금 보는 탭의 주소와 제목을 알기 위해 (누를 때만 허용됨) |

메모와 주소를 밖으로 보내지 않습니다.

## 검증한 것
- 저장 키 만들기(페이지/사이트), 검색, 내보내기 글 단위 테스트 통과.
- 실제 크롬에서 자동 저장, 페이지 메모와 사이트 메모 분리 저장, 전체 메모 검색, 글 파일 내보내기, 팝업을 닫았다 다시 열었을 때(주소 `#`가 달라도) 메모 유지 확인.

## 한계
- 이 검증에서는 "지금 보는 탭" 조회만 가짜 값으로 대체했습니다. 실제 탭의 주소를 읽는 부분은 사용해 보면서 확인이 필요합니다.
- 메모가 있는 페이지를 열었을 때 아이콘에 표시(배지)를 띄우지 않습니다. 아이콘을 눌러야 보입니다.
- 가져오기(불러오기) 기능은 없습니다.
- `chrome://` 같은 크롬 내부 페이지에는 메모를 남길 수 없습니다.
