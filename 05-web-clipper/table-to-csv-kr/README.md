# 표 → CSV 저장기

웹페이지의 표를 골라서 **엑셀에서 한글이 깨지지 않는 CSV**로 저장하거나, 엑셀에 바로 붙여넣을 수 있게 복사하는 크롬 확장 프로그램입니다. 행 수 제한과 로그인이 없습니다.

## 해결하는 문제
표를 드래그해서 복사하면 서식이 깨지고, CSV로 저장하면 엑셀에서 한글이 깨지는 일을 줄여 줍니다. 합쳐진 칸(rowspan/colspan)도 펼쳐서 저장합니다.

## 설치 방법 (처음 하는 분 기준)
1. 이 저장소에서 초록색 **Code** 버튼 → **Download ZIP**으로 내려받아 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions` 를 입력하고 Enter를 누릅니다.
3. 오른쪽 위 **개발자 모드** 스위치를 켭니다.
4. 왼쪽 위 **압축해제된 확장 프로그램을 로드합니다**를 누르고, 이 폴더(`manifest.json`이 보이는 폴더)를 고릅니다.
5. 주소창 오른쪽 퍼즐 모양 아이콘 → 이 확장의 핀 아이콘을 눌러 고정합니다.

## 사용법
1. 표가 있는 페이지에서 툴바의 확장 아이콘을 누릅니다. 페이지의 표가 목록으로 나옵니다. (칸 수, 첫 줄 미리보기)
2. 목록에서 표를 누르면 페이지에서 그 표에 **파란 테두리**가 표시됩니다.
3. **CSV로 저장**: 파일이 내려받아집니다. "엑셀에서 한글이 깨지지 않게 저장(UTF-8 BOM)"은 기본으로 켜져 있습니다.
4. **엑셀 붙여넣기용 복사**: 탭으로 구분된 글이 복사되어, 엑셀이나 구글 시트에 붙여넣으면 칸이 맞게 들어갑니다.

## 안전 처리
- 칸 값이 `=`, `@`로 시작하거나 숫자가 아닌 `+`/`-`로 시작하면 앞에 `'`를 붙여 엑셀이 수식으로 실행하지 않게 합니다. (`-35.5`, `+82-10` 같은 숫자는 그대로입니다.)
- 칸 안의 줄바꿈은 공백으로 바꿔 한 줄로 저장합니다.

## 권한이 필요한 이유
| 권한 | 이유 |
|---|---|
| `activeTab` | 아이콘을 누른 지금 이 탭의 표를 읽기 위해 (누를 때만 허용됨) |
| `scripting` | 그 탭 안에서 표를 찾고 읽는 코드를 실행하기 위해 |

모든 사이트 접근 권한은 요청하지 않으며, 표 내용을 밖으로 보내지 않습니다.

## 검증한 것
- CSV 만들기(따옴표·쉼표·BOM), 수식 무력화, 탭 구분 변환 단위 테스트 통과.
- 실제 크롬에서 표 2개 발견, 4행 × 3열 표시, 파란 테두리 표시, 합친 칸 펼침, 쉼표·따옴표 처리, 수식 무력화, BOM 있음/없음, 클립보드 복사 확인.

## 한계 (확인하지 못했거나 지원하지 않는 것)
- **툴바 아이콘을 눌러 `activeTab` 권한이 부여되는 실제 흐름은 자동 테스트로 확인하지 못했습니다.** 검증은 테스트용으로 로컬 주소 접근 권한을 더한 복사본으로 했습니다(저장소 원본의 manifest는 그대로입니다). 설치 후 한 번 직접 눌러 확인해 주세요.
- 페이지 안의 iframe 속 표 찾기는 코드로 지원하지만 테스트하지 못했습니다.
- `<table>` 태그가 아닌 `<div>`로 만든 표, 여러 페이지에 걸친 표, 자바스크립트로 나중에 그려지는 표는 지원하지 않습니다. (표가 다 그려진 뒤에 아이콘을 누르세요.)
- CSV와 복사만 지원합니다. 엑셀(.xlsx) 파일, 구글 시트 직접 내보내기는 없습니다.
- 크롬 설정 화면, 웹 스토어 같은 보호된 페이지에서는 동작하지 않습니다.
