# 마크다운 → 블로그 HTML

마크다운으로 쓴 글을 미리 보고, 블로그 HTML 모드에 붙여 넣을 깨끗한 HTML로 바꿔 복사합니다.

## 해결하는 문제
마크다운으로 글을 쓰고 티스토리 같은 블로그의 HTML 모드에 올리려면 변환 사이트를 따로 열어야 하고, 변환 결과에 불필요한 코드가 섞이거나 글 속 HTML이 그대로 실행될 위험도 있습니다. 이 확장은 브라우저 안에서 바로 변환하고, 위험한 링크와 글 속 HTML은 막습니다.

## 설치 방법 (처음 하는 분 기준)
1. 이 저장소에서 초록색 **Code** 버튼 → **Download ZIP**으로 내려받아 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions` 를 입력하고 Enter를 누릅니다.
3. 오른쪽 위 **개발자 모드** 스위치를 켭니다.
4. 왼쪽 위 **압축해제된 확장 프로그램을 로드합니다**를 누르고, 이 폴더(`manifest.json`이 보이는 `markdown-to-blog-html` 폴더)를 고릅니다.
5. 주소창 오른쪽 퍼즐 모양 아이콘 → 이 확장의 핀 아이콘을 눌러 고정합니다.

## 사용법
1. 아이콘을 누르고 왼쪽에 마크다운 글을 붙여 넣거나 씁니다. 오른쪽에 미리보기가 바로 나옵니다.
2. 필요하면 **링크를 새 창으로 열기**를 켭니다.
3. **HTML 복사하기**를 누르고 블로그 글쓰기 화면을 HTML 모드로 바꿔 붙여 넣습니다.
4. **변환된 HTML 보기**에서 결과를 확인하거나 직접 복사할 수 있습니다. 쓰던 글은 자동으로 임시 저장됩니다.

## 권한이 필요한 이유
| 권한 | 이유 |
|---|---|
| `storage` | 쓰던 글(초안)과 옵션을 내 브라우저에 임시 저장하기 위해 |

모든 사이트 접근 권한은 요청하지 않으며, 입력한 내용을 외부 서버로 보내지 않습니다.

## 검증한 것
- 변환 로직 단위 테스트 통과(제목, 굵게/기울임, 코드, 목록, 인용, 구분선, 이미지, 링크, 글 속 `<script>` 이스케이프, `javascript:` 링크 차단).
- 실제 Chromium에서 확인: 미리보기 제목 표시, 글 속 `<script>`가 실행되지 않고 글자로 보임, 새 창 옵션이 HTML에 반영, 복사한 내용 일치, 초안 새로고침 후 유지.

## 한계 (확인하지 못했거나 지원하지 않는 것)
- 지원 문법: 제목, 굵게, 기울임, `코드`, 코드 블록, 목록(한 단계), 인용, 구분선, 링크, 이미지. **표·각주·중첩 목록·체크박스는 지원하지 않습니다.**
- 글 속에 직접 적은 HTML 태그는 해석하지 않고 글자 그대로 보여 줍니다.
- 링크·이미지 주소는 http, https, mailto 만 허용합니다.
- 실제 블로그 편집기(티스토리 등)에 붙여 넣어 모양을 확인하지는 못했습니다(미검증). 블로그마다 스타일이 달라 보이는 모양은 다를 수 있습니다.
