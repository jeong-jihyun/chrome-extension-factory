# 가격 메모 (가격 변화 기록)

쇼핑 페이지의 가격을 드래그해 우클릭으로 기록하고 날짜별 변화와 최저가를 봅니다.

## 해결하는 문제
"지난주보다 올랐나?"를 기억에 의존하는 문제를 줄입니다. 쇼핑몰마다 다른 화면 구조를 읽지 않고, 내가 드래그한 가격 글자만 기록하므로 어느 쇼핑몰에서나 동작하고 모든 사이트 접근 권한이 필요 없습니다.

## 설치 방법 (처음 하는 분 기준)
1. 이 저장소에서 초록색 **Code** 버튼 → **Download ZIP**으로 내려받아 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions` 를 입력하고 Enter를 누릅니다.
3. 오른쪽 위 **개발자 모드** 스위치를 켭니다.
4. 왼쪽 위 **압축해제된 확장 프로그램을 로드합니다**를 누르고, 이 폴더(`manifest.json`이 보이는 `price-memo-kr` 폴더)를 고릅니다.
5. 주소창 오른쪽 퍼즐 모양 아이콘 → 이 확장의 핀 아이콘을 눌러 고정합니다.

## 사용법
1. 상품 페이지에서 가격 글자(예: `29,900원`)를 마우스로 드래그합니다.
2. 우클릭 → **가격 메모에 기록: "…"** 를 누릅니다. 확장 아이콘에 '저장' 표시가 잠깐 뜹니다.
3. 툴바 아이콘을 누르면 상품별 현재가, 직전 대비 오르내림(▲/▼, %), 최저가, 최근 기록이 보입니다.
4. 드래그가 안 되는 화면은 팝업의 입력칸에 가격을 적고 **기록**을 눌러도 됩니다(현재 탭 주소와 제목을 사용).
5. 같은 상품 주소는 한 줄로 모이고(`utm_` 같은 추적 값은 무시), 같은 날 같은 가격은 한 번만 쌓입니다.

## 권한이 필요한 이유
| 권한 | 이유 |
|---|---|
| `contextMenus` | 가격 글자를 드래그했을 때 우클릭 메뉴를 만들기 위해 |
| `storage` | 가격 기록을 내 브라우저에 보관하기 위해 |
| `activeTab` | 팝업에서 직접 기록할 때, 확장 아이콘을 누른 지금 이 탭의 주소·제목을 읽기 위해 (누를 때만 허용) |

모든 사이트 접근 권한은 요청하지 않으며, 입력한 내용을 밖으로 보내지 않습니다. 설정과 기록은 `chrome.storage`(내 브라우저)에만 저장됩니다.

## 검증한 것
- 실제 크롬(Chromium, 확장 불러오기)에서 시험: 서비스 워커 실행, 우클릭 메뉴 API 생성 가능, 가격 글자 해석(`29,900원`→29900, `₩ 1,250,000`), 추적용 주소 값 제거로 한 상품 합치기, 가격 두 번 기록 후 ▼ 4,900원(-16.4%)·최저가·기록 횟수 표시, 삭제, 콘솔 오류 없음.

## 한계 (확인하지 못했거나 지원하지 않는 것)
- **툴바 아이콘을 눌러 팝업을 여는 실제 흐름은 자동 테스트로 확인하지 못했습니다.** 시험은 팝업 화면 주소(`chrome-extension://…/popup.html`)를 직접 열어서 했습니다. 설치 후 한 번 직접 눌러 확인해 주세요.
- **실제 우클릭 메뉴를 눌러 기록되는 흐름과 팝업의 '기록' 버튼으로 현재 탭을 읽는 흐름은 자동 테스트로 확인하지 못했습니다(미검증).** 기록 함수만 직접 호출해 확인했습니다. 설치 후 한 번 직접 시험해 주세요.
- 가격을 자동으로 확인하러 다니지 않습니다. 가격이 바뀌었는지는 내가 다시 기록해야 알 수 있습니다(서버·상시 권한을 쓰지 않기 위한 선택).
- 선택한 글에 숫자가 여러 개면 가장 먼저 나온 숫자를 가격으로 봅니다. 원화 기준이며 통화 구분은 없습니다.
