# 한글 읽기 모드

긴 글을 **한글에 맞는 줄 바꿈과 글꼴**로 깔끔하게 보여 주는 크롬 확장 프로그램입니다. 광고·사이드바·댓글을 걷어 내고 본문만 읽을 수 있고, 읽는 시간도 알려 줍니다.

## 해결하는 문제
기사·블로그·문서를 읽을 때 광고와 메뉴 때문에 집중이 안 되고, 한글이 낱말 중간에서 끊겨 읽기 불편한 일을 줄여 줍니다. 계정, 서버, 유료 기능이 없습니다.

## 설치 방법 (처음 하는 분 기준)
1. 이 저장소에서 초록색 **Code** 버튼 → **Download ZIP**으로 내려받아 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions` 를 입력하고 Enter를 누릅니다.
3. 오른쪽 위 **개발자 모드** 스위치를 켭니다.
4. 왼쪽 위 **압축해제된 확장 프로그램을 로드합니다**를 누르고, 이 폴더(`manifest.json`이 보이는 `hangul-reader` 폴더)를 고릅니다.
5. 주소창 오른쪽 퍼즐 모양 아이콘 → 이 확장의 핀 아이콘을 눌러 고정합니다.

## 사용법
1. 읽고 싶은 글이 있는 페이지에서 툴바의 확장 아이콘을 누릅니다.
2. **읽기 모드 켜기**를 누르면 본문만 큰 화면으로 나옵니다. (제목, 읽는 시간, 글자 수, 원문 링크 표시)
3. 팝업에서 글자 크기, 줄 간격, 본문 너비, 배경(흰색·베이지·어둡게), 글꼴(고딕·명조)을 바꾸면 바로 반영되고 저장됩니다.
4. 닫으려면 **Esc** 키 또는 화면 오른쪽 위 **닫기**를 누릅니다.

## 권한이 필요한 이유
| 권한 | 이유 |
|---|---|
| `activeTab` | 아이콘을 누른 지금 이 탭의 글을 읽기 위해 (누를 때만 허용됨) |
| `scripting` | 그 탭 안에서 본문을 찾고 읽기 화면을 그리는 코드를 실행하기 위해 |
| `storage` | 글자 크기·밝기 같은 내 설정을 브라우저에 저장하기 위해 |

모든 사이트 접근 권한은 요청하지 않으며, 글 내용을 밖으로 보내지 않습니다.

## 검증한 것
- 실제 크롬(Chrome for Testing 153)에서 시험했습니다. 직접 만든 시험 글에서 본문·제목·링크·인용문·목록·큰 그림은 남고, 광고·댓글·푸터·사이드바·메뉴·작은 추적 그림은 빠지는 것을 확인했습니다.
- 설정 바꾸기가 실시간 반영, 저장 후 팝업 재실행 시 유지, Esc로 닫기, 스크롤 잠금 복구를 확인했습니다. 본문이 없는 페이지는 안내 문구가 나옵니다. (23개 항목 통과, 화면 캡처로 눈으로도 확인)

## 한계 (확인하지 못했거나 지원하지 않는 것)
- **툴바 아이콘을 눌러 `activeTab` 권한이 부여되는 실제 흐름은 자동 테스트로 확인하지 못했습니다.** 시험은 로컬 주소 접근 권한을 더한 복사본으로 했습니다(저장소 원본 manifest는 그대로). 설치 후 한 번 직접 눌러 확인해 주세요.
- 본문 찾기는 단순한 점수 방식이라 복잡한 페이지에서 틀릴 수 있습니다. 실제 뉴스·블로그 사이트로는 시험하지 못했습니다.
- 네이버 블로그처럼 글이 iframe 안에 있는 페이지, 로그인 후 보이는 글은 지원하지 않거나 시험하지 못했습니다.
- 하이라이트·메모·음성 읽기·오프라인 저장은 없습니다.
- 크롬 설정 화면, 웹 스토어 같은 보호된 페이지에서는 동작하지 않습니다.
