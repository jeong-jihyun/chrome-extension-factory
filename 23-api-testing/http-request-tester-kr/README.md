# HTTP 요청 시험기 (한글)

주소·방식·헤더·본문을 넣고 요청을 보내 **상태 코드, 걸린 시간, 크기, 응답 본문**을 한글 화면으로 확인하는 가벼운 API 시험 도구입니다.

## 해결하는 문제
API를 잠깐 확인하려고 큰 프로그램을 설치하거나 계정을 만드는 번거로움을 줄입니다. 헤더·본문은 저장하지 않아 토큰이 남지 않습니다.

## 설치 방법 (처음 하는 분용)
1. 크롬 주소창에 `chrome://extensions` 입력 후 Enter
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** 클릭
4. 이 폴더(`http-request-tester-kr`) 선택

## 사용법
1. 툴바 아이콘을 누르고 방식(GET 등)과 주소를 넣습니다.
2. 필요하면 헤더(`이름: 값`, 한 줄에 하나)와 본문을 펼쳐 적습니다.
3. **보내기**를 누르면 상태·시간·크기와 응답 본문(JSON은 보기 좋게)이 나옵니다.
4. "요청이 막혔다"는 안내가 나오면, 그 사이트에 한해 접근을 허용하는 버튼을 눌러 다시 시도할 수 있습니다.
5. 최근 주소 10개는 목록에서 다시 불러옵니다.

## 권한이 필요한 이유
- `storage`: 최근 주소(방식+주소) 10개만 저장합니다. 헤더·본문·응답은 저장하지 않습니다.
- 선택 권한(`optional_host_permissions`): 설치할 때는 어떤 사이트 권한도 받지 않습니다. 서버가 CORS를 허용하지 않아 요청이 막혔을 때만, 해당 사이트 한 곳에 한해 직접 허용할 수 있습니다.

## 한계
- 쿠키는 보내지 않습니다(`credentials: omit`). 로그인 쿠키가 필요한 API는 시험할 수 없습니다.
- 파일 업로드(멀티파트), 웹소켓, 요청 모음(컬렉션), 환경 변수 기능은 없습니다.
- 응답은 글자로만 보여 줍니다(이미지·바이너리는 깨져 보임). 1MB 넘게는 잘라 보여 줍니다.
- 브라우저 제한 때문에 일부 헤더(Host, Cookie 등)는 바꿀 수 없습니다.
- 사이트 접근 허용 버튼의 실제 허용 창 동작은 자동 시험을 하지 못해 직접 확인이 필요합니다.
