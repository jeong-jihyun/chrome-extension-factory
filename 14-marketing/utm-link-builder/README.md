# UTM 링크 만들기 (국내 채널)

현재 페이지 주소에 UTM 꼬리표를 붙이고, 네이버 블로그·카카오톡 등 국내 채널 프리셋으로 빠르게 만듭니다.

## 해결하는 문제
채널별 유입을 구분하려고 UTM 링크를 만들 때 source·medium 이름을 매번 다르게 적어 통계가 흩어집니다. 기존 확장은 영어 화면이고 국내 채널 이름이 없으며, 한글 캠페인 이름이나 띄어쓰기 처리도 직접 해야 합니다.

## 설치 방법 (처음 하는 분 기준)
1. 이 저장소에서 초록색 **Code** 버튼 → **Download ZIP**으로 내려받아 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions` 를 입력하고 Enter를 누릅니다.
3. 오른쪽 위 **개발자 모드** 스위치를 켭니다.
4. 왼쪽 위 **압축해제된 확장 프로그램을 로드합니다**를 누르고, 이 폴더(`manifest.json`이 보이는 `utm-link-builder` 폴더)를 고릅니다.
5. 주소창 오른쪽 퍼즐 모양 아이콘 → 이 확장의 핀 아이콘을 눌러 고정합니다.

## 사용법
1. 연결할 페이지를 연 상태에서 아이콘을 누르면 주소가 자동으로 채워집니다. (다른 주소를 직접 넣어도 됩니다.)
2. **채널 프리셋**에서 네이버 블로그·카카오톡 공유·인스타그램 등을 고르면 source와 medium이 채워집니다.
3. campaign(캠페인 이름)을 적습니다. 한글도 됩니다. source·medium·campaign은 꼭 필요합니다.
4. **링크 만들기** → **복사하기**. 최근 20개 링크는 아래 기록에 남습니다.
5. 이미 주소에 utm 값이 있으면 새 값으로 바꾸고, 바꾼 항목을 알려 줍니다.

## 권한이 필요한 이유
| 권한 | 이유 |
|---|---|
| `activeTab` | 아이콘을 누른 지금 이 탭의 주소를 자동으로 채우기 위해 (누를 때만 허용됨) |
| `storage` | 최근 링크 기록과 마지막 입력값을 저장하기 위해 |

모든 사이트 접근 권한은 요청하지 않으며, 입력한 내용을 외부 서버로 보내지 않습니다.

## 검증한 것
- 링크 만들기 로직 단위 테스트 통과(한글 퍼센트 인코딩, 기존 쿼리·# 보존, 기존 utm 교체, 잘못된 주소·필수값 누락 안내).
- 실제 Chromium에서 확인: 현재 탭 주소 자동 채움, 프리셋 선택, 링크 생성, 복사한 내용 일치, 기록·입력값 새로고침 후 유지, 잘못된 주소 안내(로컬 주소 접근 권한을 더한 시험용 복사본으로 확인).

## 한계 (확인하지 못했거나 지원하지 않는 것)
- 프리셋 이름(예: naver_blog)은 이 확장이 정한 예시입니다. 분석 도구에서 쓰는 이름과 맞는지 확인하세요.
- 분석 도구와 연동하거나 클릭 수를 보여 주지는 않습니다(링크만 만듭니다).
- 툴바 아이콘을 눌러 `activeTab` 권한이 주어지는 실제 흐름은 자동 테스트하지 못했습니다(미검증).
- 짧은 주소(단축 URL)는 만들지 않습니다.
