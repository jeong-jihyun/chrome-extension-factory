# 벤치마킹: 중복 탭 정리기

| 이름 | 사용자 수 | 평점 (개수) | 권한 | 마지막 업데이트 | 출처 |
|---|---|---|---|---|---|
| Close Duplicate Tabs | 533 | 5.0 (1) | 탭 접근 | 2024-09-16 | 크롬 웹 스토어 |
| Duplicate Tab Closer | 570 | 4.8 (6) | 스토어에 별도 권한 표기 없음 | 2024-10-17 | 크롬 웹 스토어 |
| Duplicate Tabs Preventor | 282 | 4.5 (4) | tabs, storage, downloads + 모든 사이트(`*://*/*`) | 날짜 표시 없음. 설명에 "2026-04부터 더 이상 유지보수하지 않음"이라고 적혀 있음 | extscope 정리 페이지 |

## 부족한 점 (확인된 범위)
- 셋 다 사용자 수가 600명 미만이고 리뷰도 거의 없어서, 리뷰에서 반복되는 불만은 **확인하지 못했다.**
- Duplicate Tabs Preventor는 모든 사이트 접근 권한을 요구하고, 유지보수가 끝났다고 밝혔다.
- 앞의 두 확장은 마지막 업데이트가 2024년이다.
- 닫기 전에 어떤 탭이 닫히는지 목록으로 보여 주는지, 되살리기가 있는지는 스토어 설명에서 확인하지 못했다.

## 이 확장의 차별점
- 사이트 접근 권한 없이 `tabs`와 `storage`만 사용한다.
- 주소 끝의 `#`과 광고 추적 꼬리표(utm 등)가 달라도 같은 페이지로 묶는다. (경쟁 확장의 비교 방식은 확인하지 못했다.)
- 닫기 전에 목록과 개수를 보여 준다. 고정 탭은 닫지 않는다.
- 방금 닫은 탭을 되살릴 수 있다.
- 한국어 화면.

## 한계
- 이 분야는 사용자 수가 모두 적어서 **수요가 크다는 근거는 약하다.** 다른 분류보다 우선순위가 낮을 수 있다.
- 자동으로 중복을 막는 기능은 없다.
