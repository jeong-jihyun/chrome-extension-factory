# 중복 탭 정리기

같은 페이지가 여러 탭에 열려 있으면 목록으로 보여 주고, 한 번에 정리하는 크롬 확장 프로그램입니다. 잘못 닫았다면 되살릴 수 있습니다.

## 해결하는 문제
검색하다 보면 같은 글이 탭 여러 개로 쌓입니다. 주소 끝의 `#`이나 광고 추적 꼬리표(`utm_source` 등)만 다른 탭도 같은 페이지로 보고 묶어 줍니다.

## 설치 방법 (처음 하는 분 기준)
1. 이 저장소에서 초록색 **Code** 버튼 → **Download ZIP**으로 내려받아 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions` 를 입력하고 Enter를 누릅니다.
3. 오른쪽 위 **개발자 모드** 스위치를 켭니다.
4. 왼쪽 위 **압축해제된 확장 프로그램을 로드합니다**를 누르고, 이 폴더(`manifest.json`이 보이는 폴더)를 고릅니다.
5. 주소창 오른쪽 퍼즐 모양 아이콘 → 이 확장의 핀 아이콘을 눌러 고정합니다.

## 사용법
1. 툴바의 확장 아이콘을 누르면 바로 검사해서 "중복된 페이지 N곳, 닫을 탭 M개"를 보여 줍니다.
2. 위쪽 체크박스로 `#` 무시, 광고 꼬리표 무시, 모든 창 검사 여부를 바꿀 수 있습니다.
3. **중복 탭 닫기**를 누르면 닫습니다. 남기는 탭은 **고정 탭 > 지금 보는 탭 > 먼저 열린 탭** 순서입니다.
4. 고정된 탭은 중복이어도 닫지 않습니다.
5. 잘못 닫았으면 **방금 닫은 탭 되살리기**로 다시 엽니다. (주소만 다시 열며, 입력하던 내용은 복원되지 않습니다.)

## 권한이 필요한 이유
| 권한 | 이유 |
|---|---|
| `tabs` | 열린 탭의 주소를 읽고 중복 탭을 닫기 위해 |
| `storage` | 방금 닫은 탭의 주소를 저장해서 되살릴 수 있게 하기 위해 |

사이트 접근 권한(host permissions)은 요청하지 않습니다. 탭 주소는 밖으로 보내지 않습니다.

## 검증한 것
- 주소 정규화·남길 탭 선택 단위 테스트 통과.
- 실제 크롬에서 같은 페이지 3개(원본, `#top`, `?utm_source=ad`)와 다른 페이지 1개를 열고, 2개가 닫히고 먼저 연 탭이 남는 것, 되살리기로 2개가 다시 열리는 것을 확인.

## 한계
- 팝업을 일반 탭으로 열어 검증했습니다. 툴바 아이콘을 눌러 여는 방식과 여러 창에 걸친 중복은 직접 확인하지 못했습니다.
- 탭을 열 때 중복을 자동으로 막는 기능은 없습니다. 눌렀을 때만 정리합니다.
- 되살리기는 마지막 1회분만 저장합니다.
