# 버그 신고 환경 정보 모으기

버그를 신고할 때 개발자가 꼭 묻는 **주소·브라우저·운영체제·화면 크기·배율** 등을 한 번에 모아 한글 신고 양식으로 만들어 복사합니다.

## 해결하는 문제
"안 돼요"라고만 보내면 개발자가 환경을 되묻느라 시간이 걸립니다. 직접 알아내기 어려운 값(화면 배율, 확대 정도, 사용자 에이전트)을 클릭 한 번으로 채웁니다.

## 설치 방법 (처음 하는 분용)
1. 크롬 주소창에 `chrome://extensions` 입력 후 Enter
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** 클릭
4. 이 폴더(`bug-report-env-kr`)를 선택

## 사용법
1. 버그가 난 웹 페이지 탭에서 툴바 아이콘을 누릅니다.
2. **이 탭 정보 모으기**를 누르면 양식이 만들어집니다.
3. "무엇이 문제인가요?"와 재현 순서를 직접 적고 **복사**해서 이슈·메일·메신저에 붙여 넣습니다.
4. 기본으로 주소의 `?` 뒤(검색어·토큰이 들어 있을 수 있음)는 지웁니다. 체크를 해제하면 전체 주소가 들어갑니다.

## 권한이 필요한 이유
- `activeTab`: 아이콘을 누른 그 탭에서만 잠깐 정보를 읽습니다. 모든 사이트 접근 권한은 요청하지 않습니다.
- `scripting`: 그 탭 안에서 화면 크기 등을 읽는 작은 함수를 한 번 실행합니다.
- `storage`: "주소 ? 뒤 지우기" 체크 상태만 저장합니다.

## 한계
- 크롬 설정 페이지(`chrome://`)나 웹스토어에서는 정보를 읽을 수 없습니다.
- 콘솔 오류나 네트워크 기록은 모으지 않습니다(환경 정보 전용).
- 화면 확대 정도는 창 크기 비율로 어림한 값이라 정확하지 않을 수 있습니다.
- 주소창·제목에 개인정보가 있을 수 있으니 붙여 넣기 전에 직접 확인하세요.
