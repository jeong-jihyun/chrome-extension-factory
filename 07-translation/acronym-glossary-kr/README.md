# 영문 약어 한글 풀이

웹페이지에 나오는 **PER, ETF, API, KPI** 같은 영문 약어에 마우스를 올리면 **한글 이름과 쉬운 설명**을 보여 주는 크롬 확장 프로그램입니다. 내 용어도 추가할 수 있습니다.

## 해결하는 문제
증권 리포트, IT 문서, 광고·SEO 글을 읽다가 약어 뜻을 찾으려고 검색 탭을 여는 일을 줄여 줍니다. 서버로 아무것도 보내지 않고, 이 PC 안에서만 동작합니다.

## 설치 방법 (처음 하는 분 기준)
1. 이 저장소에서 초록색 **Code** 버튼 → **Download ZIP**으로 내려받아 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions` 를 입력하고 Enter를 누릅니다.
3. 오른쪽 위 **개발자 모드** 스위치를 켭니다.
4. 왼쪽 위 **압축해제된 확장 프로그램을 로드합니다**를 누르고, 이 폴더(`manifest.json`이 보이는 `acronym-glossary-kr` 폴더)를 고릅니다.
5. 주소창 오른쪽 퍼즐 모양 아이콘 → 이 확장의 핀 아이콘을 눌러 고정합니다.

## 사용법
1. 약어가 있는 페이지에서 툴바의 확장 아이콘을 누르고 **이 페이지 약어 풀이 켜기**를 누릅니다.
2. 사전에 있는 약어에 **점선 밑줄**이 생깁니다. 마우스를 올리면 `약어 · 한글 이름`, 영문 풀이, 쉬운 설명이 나옵니다.
3. **끄기**를 누르면 표시가 모두 사라지고 글은 원래대로 돌아갑니다.
4. 사내 용어 등은 팝업의 **내 용어 추가**에 약어와 한글 이름(설명은 선택)을 넣고 **추가**를 누릅니다. 켜져 있다면 껐다가 다시 켜면 적용됩니다.
5. 내장 사전이 방해되면 **내장 사전 사용** 체크를 끄세요. 그러면 내 용어만 표시됩니다.

## 권한이 필요한 이유
| 권한 | 이유 |
|---|---|
| `activeTab` | 아이콘을 누른 지금 이 탭의 글에서 약어를 찾기 위해 (누를 때만 허용됨) |
| `scripting` | 그 탭 안에서 약어를 찾고 툴팁을 보여 주는 코드를 실행하기 위해 |
| `storage` | 내가 추가한 용어와 설정을 브라우저에 저장하기 위해 |

모든 사이트 접근 권한은 요청하지 않으며, 페이지 글을 밖으로 보내지 않습니다.

## 검증한 것
- 실제 크롬(Chrome for Testing 153)에서 시험했습니다. PER·PBR·ETF·KPI·M&A·CI/CD·API·FIX와 내가 추가한 SKP가 표시되고, `SAPI`처럼 영문이 붙은 낱말과 사전에 없는 `T+2`는 표시되지 않았습니다.
- 편집 가능한 칸, textarea, `<script>` 안의 글은 건드리지 않고, 끄면 글이 원래와 똑같이 돌아오는 것을 확인했습니다. 마우스를 올리면 툴팁이 나오고 치우면 사라지며, 내장 사전을 끄면 내 용어만 표시됩니다. 화면 캡처로 눈으로도 확인했습니다.

## 한계 (확인하지 못했거나 지원하지 않는 것)
- **툴바 아이콘을 눌러 `activeTab` 권한이 부여되는 실제 흐름은 자동 테스트로 확인하지 못했습니다.** 시험은 로컬 주소 접근 권한을 더한 복사본으로 했습니다(저장소 원본 manifest는 그대로). 설치 후 한 번 직접 눌러 확인해 주세요.
- 내장 사전은 83개뿐이고, 설명은 일반적인 뜻입니다. 회사·업종에 따라 다르게 쓰는 경우가 있어 정확성을 보증하지 않습니다.
- 같은 약어가 다른 뜻으로 쓰이는 경우를 구분하지 못합니다.
- 켠 뒤에 새로 불러온 글(무한 스크롤 등)과 iframe 안의 글에는 적용되지 않습니다. 다시 켜면 새로 찾습니다.
- 크롬 설정 화면, 웹 스토어 같은 보호된 페이지에서는 동작하지 않습니다.
