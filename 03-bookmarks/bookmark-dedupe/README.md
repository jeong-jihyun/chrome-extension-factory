# 북마크 중복 정리기

중복된 북마크와 빈 폴더를 찾아 보여 주고, **백업을 저장한 뒤** 내가 고른 것만 정리하는 크롬 확장 프로그램입니다.

## 해결하는 문제
오래 쓰다 보면 같은 페이지가 여러 폴더에 북마크됩니다. 주소 끝의 `#`이나 광고 추적 꼬리표(`utm_source` 등)만 달라도 같은 페이지로 봅니다.

## 설치 방법 (처음 하는 분 기준)
1. 이 저장소에서 초록색 **Code** 버튼 → **Download ZIP**으로 내려받아 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions` 를 입력하고 Enter를 누릅니다.
3. 오른쪽 위 **개발자 모드** 스위치를 켭니다.
4. 왼쪽 위 **압축해제된 확장 프로그램을 로드합니다**를 누르고, 이 폴더(`manifest.json`이 보이는 폴더)를 고릅니다.
5. 주소창 오른쪽 퍼즐 모양 아이콘 → 이 확장의 핀 아이콘을 눌러 고정합니다.

## 사용법
1. 툴바의 확장 아이콘 → **검사하기**.
2. 중복 묶음마다 어느 폴더에 있는지 보입니다. **남길 북마크**를 라디오 버튼으로 고릅니다. (기본은 가장 먼저 저장한 것)
3. 빈 폴더는 체크된 것만 삭제됩니다. 빼고 싶으면 체크를 해제하세요.
4. **1) 백업 저장(JSON)**을 누릅니다. 전체 북마크가 파일로 저장됩니다.
5. 백업을 저장해야 **2) 선택한 항목 정리**가 켜집니다. 누르면 삭제됩니다.

> 삭제한 북마크는 이 확장으로 되돌릴 수 없습니다. 백업 파일은 크롬의 북마크 관리자에서 가져오는 HTML 형식이 아니라 JSON 형식입니다.

## 권한이 필요한 이유
| 권한 | 이유 |
|---|---|
| `bookmarks` | 북마크를 읽고 중복·빈 폴더를 삭제하기 위해 |

그 밖의 권한은 없습니다. 북마크 주소를 밖으로 보내거나 열어 보지 않습니다.

## 검증한 것
- 중복 묶음, 오래된 순 정렬, 빈 폴더 판정(가장 바깥 빈 폴더만) 단위 테스트 통과.
- 실제 크롬에서 북마크를 만들어 검사 → 백업 파일 저장(JSON) → 정리까지 실행. 중복은 1개만 남고, 먼저 저장한 것이 남고, 유일한 북마크는 유지되고, 빈 폴더는 삭제되고, 북마크바 같은 기본 폴더는 유지되는 것을 확인.

## 한계
- **죽은 링크 검사와 비슷한 폴더 합치기는 없습니다.** 이런 기능이 필요하면 아래 BENCHMARK의 다른 확장이 더 낫습니다.
- 북마크 수천 개 규모의 속도는 확인하지 못했습니다.
- 백업 파일을 다시 가져오는 기능은 없습니다. 복원이 필요하면 JSON을 열어 직접 확인해야 합니다.
- 구글 계정 동기화를 켜 두었다면 삭제가 다른 기기에도 반영됩니다.
