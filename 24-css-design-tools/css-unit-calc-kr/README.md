# CSS 단위·clamp 계산기

px · rem · em · vw 단위를 서로 바꿔 주고, 화면 너비에 따라 글자 크기가 부드럽게 변하는 `clamp()` 값을 만들어 주는 확장 프로그램입니다.

## 해결하는 문제
`clamp(1rem, 0.6rem + 1.5vw, 1.5rem)` 같은 값은 손으로 계산하기 어렵습니다. 최소·최대 글자 크기와 화면 너비만 넣으면 CSS 한 줄을 만들어 주고, 몇몇 화면 너비에서 실제 크기가 몇 px인지 확인해 줍니다.

## 설치 방법 (처음 하는 분용)
1. 크롬 주소창에 `chrome://extensions` 입력 후 Enter
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** 클릭
4. 이 폴더(`css-unit-calc-kr`) 선택

## 사용법
- **단위 바꾸기**: 값과 단위를 고르면 나머지 단위 값이 바로 나옵니다. 기준 글자 크기(보통 16px)와 vw 계산용 화면 너비를 바꿀 수 있습니다.
- **clamp() 만들기**: 가장 작을 때·클 때 글자 크기와 작은·큰 화면 너비를 넣으면 `font-size: clamp(...)` 한 줄이 나옵니다. **복사**를 누르세요.
- 입력한 숫자는 다음에 열 때를 위해 저장됩니다.

## 권한이 필요한 이유
- `storage`: 마지막에 입력한 숫자만 저장합니다. 그 밖의 권한은 없고 웹 페이지에도 접근하지 않습니다.

## 한계
- em은 부모 글자 크기를 모르므로 rem과 같은 기준(기준 글자 크기)으로 계산합니다.
- vw는 화면 스크롤바 폭을 빼지 않은 값으로 계산합니다.
- 글자 크기용 clamp()만 만듭니다(여백 등 다른 속성은 같은 식으로 직접 응용).
- 사용자가 브라우저 기본 글자 크기를 바꾼 경우 rem 결과는 그에 따라 달라집니다.
