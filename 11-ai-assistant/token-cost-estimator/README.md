# AI 토큰·비용 어림 계산기

프롬프트 글의 토큰 수와 예상 비용, 컨텍스트 사용 비율을 한글 기준으로 어림해 줍니다.

## 해결하는 문제
AI 서비스는 글자가 아니라 '토큰'으로 한도와 요금을 계산합니다. 한글은 영어보다 토큰을 더 많이 쓰는 편인데, 기존 토큰 계산 확장은 대부분 영어 화면이거나 특정 사이트(ChatGPT 등) 안에서만 동작합니다. 이 확장은 어떤 서비스를 쓰든 글을 붙여 넣기만 하면 어림값을 바로 보여 줍니다.

## 설치 방법 (처음 하는 분 기준)
1. 이 저장소에서 초록색 **Code** 버튼 → **Download ZIP**으로 내려받아 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions` 를 입력하고 Enter를 누릅니다.
3. 오른쪽 위 **개발자 모드** 스위치를 켭니다.
4. 왼쪽 위 **압축해제된 확장 프로그램을 로드합니다**를 누르고, 이 폴더(`manifest.json`이 보이는 `token-cost-estimator` 폴더)를 고릅니다.
5. 주소창 오른쪽 퍼즐 모양 아이콘 → 이 확장의 핀 아이콘을 눌러 고정합니다.

## 사용법
1. 계산할 글을 페이지에서 **드래그**한 뒤 확장 아이콘 → **선택한 글 가져오기**를 누릅니다. (직접 붙여 넣어도 됩니다.)
2. 글자 수, 어림 입력 토큰, 입력 비용, 예상 출력 비용, 합계, 컨텍스트 사용 비율이 나옵니다.
3. **내 설정**에서 쓰는 서비스의 입력·출력 단가(100만 토큰당), 예상 출력 토큰, 컨텍스트 한도를 직접 넣습니다. 값은 저장됩니다.
4. 한글·영문 글자당 토큰 비율도 바꿀 수 있습니다. 실제 사용량과 비교해 맞춰 두면 더 정확해집니다.

## 권한이 필요한 이유
| 권한 | 이유 |
|---|---|
| `activeTab` | 아이콘을 누른 지금 이 탭에서 내가 드래그한 글을 가져오기 위해 (누를 때만 허용됨) |
| `scripting` | 그 탭에서 선택한 글을 읽는 코드를 실행하기 위해 |
| `storage` | 단가·한도·비율 같은 내 설정을 저장하기 위해 |

모든 사이트 접근 권한은 요청하지 않으며, 입력한 내용을 외부 서버로 보내지 않습니다.

## 검증한 것
- 계산 로직 단위 테스트 통과(글자 종류별 세기, 비용, 컨텍스트 비율, 빈 글, 이모지).
- 실제 Chromium에서 확인: 한글 100자 → 어림 150토큰, 단가 입력 시 합계 `0.0155`, 컨텍스트 한도 1000일 때 `115.0%` 표시, 설정 새로고침 후 유지, 페이지에서 드래그한 글 가져오기(로컬 주소 접근 권한을 더한 시험용 복사본으로 확인).

## 한계 (확인하지 못했거나 지원하지 않는 것)
- **토큰 수는 어림값입니다.** 실제 토크나이저를 쓰지 않고 글자 종류별 비율(기본: 한글 1.5, 영문 0.25, 기타 0.6)로 계산합니다. 모델마다 실제 값이 다릅니다.
- 요금 단가는 넣어 두지 않았습니다(가격이 자주 바뀌어서). 서비스 가격표를 보고 직접 넣어야 합니다.
- 채팅 화면에 자동으로 붙지 않습니다(붙여 넣기·드래그 방식).
