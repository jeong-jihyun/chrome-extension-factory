# 한국형 SEO 메타 점검

지금 보는 페이지의 제목·설명·대표 주소·제목 태그·이미지 alt를 점검하고 검색 결과 미리보기를 보여 줍니다.

## 해결하는 문제
블로그나 쇼핑몰을 운영할 때 페이지마다 SEO 기본 항목을 눈으로 확인하기 어렵습니다. 기존 확장은 영어 화면이고 한국 환경(한국어 lang, 네이버 서치어드바이저 소유확인, 카카오톡 공유 미리보기용 og 태그)을 따로 살펴 주지 않습니다.

## 설치 방법 (처음 하는 분 기준)
1. 이 저장소에서 초록색 **Code** 버튼 → **Download ZIP**으로 내려받아 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions` 를 입력하고 Enter를 누릅니다.
3. 오른쪽 위 **개발자 모드** 스위치를 켭니다.
4. 왼쪽 위 **압축해제된 확장 프로그램을 로드합니다**를 누르고, 이 폴더(`manifest.json`이 보이는 `seo-meta-check-kr` 폴더)를 고릅니다.
5. 주소창 오른쪽 퍼즐 모양 아이콘 → 이 확장의 핀 아이콘을 눌러 고정합니다.

## 사용법
1. 점검할 페이지를 연 상태에서 확장 아이콘 → **이 페이지 점검하기**를 누릅니다.
2. 검색 결과에서 보일 모습(제목·주소·설명)과 항목별 점검 결과(양호/확인/문제)가 나옵니다.
3. 점검 항목: 제목 길이, 메타 설명 길이, canonical, noindex, html lang, viewport, H1 개수, og:title·og:image, 이미지 alt, 네이버 소유확인 태그.
4. 아래 **기준 길이 바꾸기**에서 제목·설명 기준 글자 수를 바꾸면 저장됩니다.

## 권한이 필요한 이유
| 권한 | 이유 |
|---|---|
| `activeTab` | 아이콘을 누른 지금 이 탭의 메타 정보를 읽기 위해 (누를 때만 허용됨) |
| `scripting` | 그 탭에서 메타 정보를 읽는 코드를 실행하기 위해(읽기만 하고 페이지를 바꾸지 않음) |
| `storage` | 기준 글자 수 설정을 저장하기 위해 |

모든 사이트 접근 권한은 요청하지 않으며, 입력한 내용을 외부 서버로 보내지 않습니다.

## 검증한 것
- 점검 로직 단위 테스트 통과(문제가 있는 페이지/좋은 페이지/미리보기 자르기).
- 실제 Chromium에서 확인: 제목 35자 경고, H1 2개 경고, alt 없는 이미지 1개 감지, 짧은 설명 경고, 미리보기 주소 표시, 기준 길이를 40으로 바꾸면 `적당`으로 바뀜(로컬 주소 접근 권한을 더한 시험용 복사본으로 확인).

## 한계 (확인하지 못했거나 지원하지 않는 것)
- 기본 기준(제목 30자, 설명 70~90자)은 흔히 쓰는 **어림 기준**이며 검색엔진의 공식 값이 아닙니다. 바꿔서 쓰세요.
- 검색 결과 미리보기는 실제 네이버·구글 화면과 다를 수 있는 모양 예시입니다.
- 지금 열린 한 페이지만 봅니다. 사이트 전체 검사, 순위 확인, 속도 측정은 하지 않습니다.
- 자바스크립트가 나중에 만드는 메타 태그는 읽는 시점에 따라 빠질 수 있습니다.
- 툴바 아이콘을 눌러 `activeTab` 권한이 주어지는 실제 흐름은 자동 테스트하지 못했습니다(미검증). 설치 후 한 번 직접 눌러 확인해 주세요.
