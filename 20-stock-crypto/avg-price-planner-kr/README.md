# 평균 단가 계획기 (물타기 계산)

여러 번 나눠 산 주식·코인의 평균 단가를 구하고 목표 평단까지 몇 개를 더 사야 하는지 알려 줍니다.

## 해결하는 문제
분할 매수 후 평단을 손으로 계산하다 틀리거나, "평단을 80으로 낮추려면 60에 몇 주를 사야 하지?"를 바로 알기 어려운 문제를 풀어 줍니다. 주식·코인 모두 소수 수량을 지원합니다.

## 설치 방법 (처음 하는 분 기준)
1. 이 저장소에서 초록색 **Code** 버튼 → **Download ZIP**으로 내려받아 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions` 를 입력하고 Enter를 누릅니다.
3. 오른쪽 위 **개발자 모드** 스위치를 켭니다.
4. 왼쪽 위 **압축해제된 확장 프로그램을 로드합니다**를 누르고, 이 폴더(`manifest.json`이 보이는 `avg-price-planner-kr` 폴더)를 고릅니다.
5. 주소창 오른쪽 퍼즐 모양 아이콘 → 이 확장의 핀 아이콘을 눌러 고정합니다.

## 사용법
1. 툴바의 확장 아이콘을 누릅니다.
2. 산 가격과 수량을 한 줄씩 적고 **매수 줄 추가**로 늘립니다. (통화는 상관없고 같은 단위로만 쓰면 됩니다.)
3. 위쪽에 평균 단가, 보유 수량, 총 매수금액이 나옵니다. **현재가**를 넣으면 평가손익과 수익률도 나옵니다.
4. **추가 매수 계획**: 추가 매수가와 목표 평단을 넣으면 필요한 수량과 돈을, 추가 매수가와 살 수량을 넣으면 새 평단을 보여 줍니다.
5. 입력은 자동 저장됩니다. **모두 지우기**로 초기화합니다.

## 권한이 필요한 이유
| 권한 | 이유 |
|---|---|
| `storage` | 매수 내역 입력을 내 브라우저에 저장하기 위해 |

모든 사이트 접근 권한은 요청하지 않으며, 입력한 내용을 밖으로 보내지 않습니다. 설정과 기록은 `chrome.storage`(내 브라우저)에만 저장됩니다.

## 검증한 것
- 실제 크롬(Chromium, 확장 불러오기)에서 팝업 시험: (100×10, 80×10) → 평균 90, 현재가 70이면 -22.22%, 추가 매수가 60·목표 평단 80 → 10개 필요, 목표가 평단보다 높으면 안내 문구, 살 수량 10개 → 평단 80, 저장 후 다시 열어도 유지, 콘솔 오류 없음.

## 한계 (확인하지 못했거나 지원하지 않는 것)
- **툴바 아이콘을 눌러 팝업을 여는 실제 흐름은 자동 테스트로 확인하지 못했습니다.** 시험은 팝업 화면 주소(`chrome-extension://…/popup.html`)를 직접 열어서 했습니다. 설치 후 한 번 직접 눌러 확인해 주세요.
- 수수료·세금·환율은 계산에 넣지 않았습니다(순손익은 같은 분류의 '주식 수수료·세금 손익 계산기' 확장을 쓰세요).
- 실시간 시세를 가져오지 않으므로 현재가는 직접 입력해야 합니다. 매도 이력(실현손익)은 다루지 않습니다. 투자 조언이 아닙니다.
